# enterprise-gcp-llm-deploy-enterprise

Enterprise-grade deployment repository for production LLM inference on GKE.

Enhancements included:
- configurable PDBs
- advanced rollout controls
- prewarming jobs
- configurable observability
- Redis HA integration
- multi-env overlays
- GPU affinity/tolerations
- CPU/GPU separation awareness
- topology spread constraints
- maintenance-safe rolling upgrades
- namespace quotas
- warm pool support
- configurable HPA/KEDA
- optional spot GPU scheduling
